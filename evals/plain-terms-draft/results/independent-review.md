## 어느 쪽이 자연스러운가

X가 더 자연스럽다. 같은 자료 문장에서 X는 사람 글이 쓰는 말을 쓰고 Y는 사전의 대응어나 고유어를 쓴다. Y는 메모리, MB, 대기 상태, 잠금, 네트워크 드라이브, 설정 파일을 여러 번 정의한다. X는 한 번씩 정의한다.

X가 더 못한 곳도 있다. "이전 버전인 Python 버전의 바이너리 복사본을 새 버전인 Rust 버전의 바이너리 옆에"는 수식어가 겹치고, "버전 번호로는 1.8 버전이 Python으로 작성한 마지막 버전이고"는 Y의 "마지막 Python 버전은 1.8 버전이고"보다 길다. 락, update checker, worker를 다룬 절은 정의문이 연달아 나온다.
