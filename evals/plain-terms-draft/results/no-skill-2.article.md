# 동기화 에이전트를 Python에서 Rust로 옮기며 유휴 메모리를 210MB에서 38MB로 줄인 과정

> 이 글은 글쓰기 평가용으로 작성된 가상의 내부 노트를 정리한 것입니다. 글에 나오는 수치와 사례를 실제 결과로 인용하면 안 됩니다.

회사 노트북 약 4,000대에서 실행되는 동기화 에이전트(sync agent)를 Python에서 Rust로 다시 만든 사례를 정리합니다. 노트북 500대에서 2주 동안 측정한 결과, 유휴 메모리는 210MB에서 38MB로, 시작 시간은 1.9초에서 0.3초로 줄었습니다. 다만 약 120대는 보안 도구 때문에 아직 Python 버전을 쓰고 있고, 네트워크 드라이브에서 어떻게 동작하는지는 아직 확인하지 못했습니다.

## Rust 버전을 만든 이유

Python 버전은 2023년부터 운영 환경에서 쓰였습니다. 이 버전은 아무 작업도 하지 않는 유휴 상태에서도 메모리를 210MB 사용했고, 시작하는 데 1.9초가 걸렸습니다. 그래서 팀은 3월에 Rust 버전 개발을 시작했습니다. 마이그레이션이 끝날 때까지는 이 팀이 두 버전을 모두 책임집니다.

## 6주 동안 두 버전을 함께 배포

설치 프로그램은 6주 동안 Python 버전과 Rust 버전을 함께 배포했습니다. Python 버전의 마지막 릴리스는 1.8이고, Rust 버전의 첫 릴리스는 2.0입니다.

두 버전은 같은 설정 파일을 읽습니다. 그래서 노트북을 Rust 버전으로 옮겼다가 다시 Python 버전으로 되돌려도 설정이 사라지지 않았습니다.

롤백도 간단합니다. 설치 프로그램이 새 바이너리 옆에 이전 바이너리 사본을 남겨 두기 때문에, 이전 버전으로 돌아가는 데 40초면 되고 내려받을 파일도 없습니다.

Rust 버전은 시작할 때 레지스트리에서 설치된 버전 번호를 읽고, 그 번호가 1.6보다 오래되었으면 실행을 거부합니다. 최신 버전은 항상 업데이트 서버에 올리며, 패치 릴리스는 2.0.3처럼 세 번째 숫자만 바꿉니다.

## 테스트가 찾아낸 버그 22개

테스트 스위트에는 테스트가 1,240개 있습니다. Rust로 처음 빌드했을 때 이 중 31개가 실패했습니다. 9개는 Python 버전에서도 실패하던 테스트여서 회귀(이전에 되던 동작이 깨지는 문제)가 아니었고, 나머지 22개가 실제 버그였습니다.

가장 심각한 버그는 파일 감시 기능에 있었습니다. 사용자가 폴더 이름을 바꾸면, Rust 버전은 그 뒤로 해당 폴더 안에서 일어나는 변경을 전부 놓쳤습니다. 이 버그는 2.0.3에서 고쳤고, 이제 테스트 스위트도 폴더 이름을 바꾸는 경우를 검사합니다. 네트워크 드라이브는 아직 테스트 범위에 들어 있지 않습니다.

## 파일 감시 라이브러리 비교

팀은 Lee et al. (2024)의 벤치마크로 파일 감시 라이브러리를 비교했습니다. 벤치마크에 포함된 라이브러리 12개 중 Windows 정션(폴더를 다른 위치의 폴더에 연결하는 기능)을 지원하는 것은 3개입니다.

논문은 감시 항목 수와 메모리 사용량 사이의 상관계수를 r = 0.91로 보고합니다. 1에 가까운 값이므로, 감시 항목이 많을수록 메모리도 많이 쓰는 경향이 강하다는 뜻입니다. 이 논문은 arXiv 공개본과 IEEE 출판본의 수식 번호가 서로 달라서, 내부 노트에서는 IEEE 출판본의 번호를 기준으로 삼았습니다.

## 설계 문서의 용어 정리

에이전트는 동기화가 실행되는 동안 데이터베이스 파일에 잠금(lock)을 걸어 둡니다. 설계 문서의 첫 초안은 이 잠금의 동작 방식을 잘못 설명했고, 두 번째 판에서는 해당 절을 삭제했습니다. 리뷰어는 현재 문서를 HEAD 커밋에 있는 문서와 비교해 검토했습니다.

초안에는 다른 문제도 있었습니다. "sync"와 "commit" 같은 단어가 두 가지 뜻으로 쓰였던 것입니다. 작성자들은 단어마다 뜻을 하나만 남기고, 모든 용어에 짧은 정의를 붙였습니다. 이 점검은 절마다 반복했고, 부록은 대상에서 제외했습니다.

## 측정 결과

Rust 버전은 노트북 500대에서 2주 동안 측정했습니다.

| 항목 | Python 버전 | Rust 버전 |
| --- | --- | --- |
| 유휴 메모리 | 210MB | 38MB |
| 시작 시간 | 1.9초 | 0.3초 |
| 동기화 1회당 로그 | 약 40줄 | 1줄 |

## 남은 과제

약 120대의 노트북은 보안 도구가 Rust 바이너리를 차단해서 아직 Python 버전을 쓰고 있습니다.

네트워크 드라이브에서 Rust 버전이 Python 버전과 똑같이 동작하는지도 아직 알 수 없습니다. 그 환경에서 테스트해 본 사람이 아무도 없기 때문입니다.
