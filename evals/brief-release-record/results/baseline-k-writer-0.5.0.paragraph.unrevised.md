K-Writer 0.5.0은 write와 brief 스킬을 추가했고 techblog의 short 모드는 삭제해 짧은 글을 brief로 작성하게 했습니다. write는 자료나 주제, 목적, 분량, 어투 중 요청에 없는 값을 묻고 글을 쓰며 brief는 분량과 어투만 묻습니다. core의 어투에는 Plain(해라체)과 사용자가 직접 정한 어투를 추가했습니다. 영어 엔지니어링 노트를 한 문단으로 요약하는 brief 테스트 실행에서 요약은 590자였고 기본 독자와 분량 기준을 수정한 뒤 같은 요청에서 296자로 줄었습니다. 다만 claude plugin eval과 dogfood는 실행하지 않았고 마지막 테스트 실행 뒤에 수정한 내용도 다시 실행해 확인하지 않았습니다.
