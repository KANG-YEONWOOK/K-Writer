자료는 API rate limiter를 fixed window 방식에서 token bucket 방식으로 바꾼 엔지니어링 노트다. 자료의 결론은 방식을 바꾼 뒤 초당 최대 부하가 4,800건에서 1,400건으로, gateway p99 latency가 1,850 ms에서 420 ms로 줄었다는 것이다.

요약의 제목과 "자료:"로 시작하는 줄을 제외한 첫 문장을 읽는다.

PASS: 첫 문장이 무엇을 바꿨고 그 결과 무엇이 어떻게 됐는지를 말한다.
FAIL: 첫 문장이 "이 문서는 ~를 다룹니다", "~에 대한 노트입니다"처럼 자료가 무엇을 다루는지만 소개하고 결과를 말하지 않는다. 또는 첫 문장이 인사나 요약을 시작한다는 말이다.
