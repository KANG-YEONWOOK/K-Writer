# 인자와 설정

SKILL.md 다음에 읽는 문서다. 인자를 해석하고 요청에 없는 설정값을 사용자에게 물어 정한 뒤 작업을 시작한다. 묻는 순서와 지킬 규칙은 [settings-protocol.md](settings-protocol.md)를 읽고 따른다. brief는 글의 목적을 요약으로 정해 둔 스킬이므로 분량과 어투만 묻는다. 설정을 정하기 전에는 자료를 읽거나 fact sheet를 만들지 않는다.

## 인자

- `default`, `Default`, `합니다체`: 어투를 Default로 정한다. `casual`, `Casual`, `해요체`: 어투를 Casual로 정한다. `plain`, `Plain`, `해라체`, "~다로 끝나게": 어투를 Plain으로 정한다. "개조식으로", "반말로"처럼 그 밖의 어투를 적으면 사용자가 직접 정한 어투로 처리한다.
- `-o <경로>`: 요약을 저장할 파일 경로다. 없으면 요약을 대화에만 답한다.
- `--keep-work`: 작업 파일을 삭제하지 않는다.
- `--defaults`: 분량과 어투를 묻지 않는다. 요청에 없는 값은 기본값을 사용한다. 요청에 "기본값으로", "묻지 말고"가 있어도 같다.
- 나머지 입력은 자료(파일 경로, URL)와 추가 지시다. 아래 지시는 설정값으로 해석하고 다시 묻지 않는다.
  - 분량: "한 줄로", "세 줄로", "500자 이내로", "한 문단으로", "자세히"
  - 형식: "항목으로", "불릿으로", "목록으로", "표로". 형식 지시가 있으면 [genre.md](genre.md)의 "분량별 형식"에서 그 형식을 따른다. 형식만 있고 분량이 없으면 분량은 따로 정한다.
  - 독자: "임원에게 보고할", "개발자가 아닌 사람이 읽을". 독자 지시가 없으면 기본 독자를 사용한다.
  - 초점: "비용 중심으로", "결정 사항만". 초점 지시가 있으면 요약에 남길 내용을 그 초점으로 선택한다.

## 반드시 받는 값

요약할 자료는 반드시 받는 값이다. 기본값이 없다.

- 자료는 파일 경로, URL, 대화에 붙여넣은 텍스트다. "위 내용 요약해줘", "지금까지 대화 요약해줘"처럼 대화의 앞부분을 가리키면 그 부분이 자료다. 자료가 여러 개면 모두 사용한다.
- 요청에도 대화에도 요약할 자료가 없으면 대화에서 "어떤 자료나 내용을 요약할까요? 파일 경로, URL, 붙여넣은 텍스트를 알려 주세요."라고 묻고 답을 기다린다. 답을 받은 뒤에 나머지 값을 묻는다.
- 질문할 수 없는 실행에서 자료가 없으면 요약하지 않고 자료가 필요하다고 보고한다.

## 설정값

| 값 | 기본값 | 선택지 | 사용 위치 |
|---|---|---|---|
| 분량 | 한 문단(3~5문장, 공백 제외 150~300자) | 한 줄(한두 문장, 120자 이내), 한 문단, 자세히(자료의 큰 부분마다 한 문단이나 한 항목, 800~1,200자), 직접 입력 | fact sheet의 "분량" 줄, 요약의 형식 |
| 어투 | Default(합니다체) | Default(합니다체), Casual(해요체), Plain(해라체), 직접 입력 | 6단계 어투 적용 |

- 기본 독자는 자료를 읽지 않았고 자료가 대상으로 삼은 독자와 같은 수준의 지식이 있는 사람이다. 자료가 설명 없이 사용하는 용어는 요약에서도 설명하지 않는다. 사용자가 독자를 정하면(예: "개발자가 아닌 사람이 읽을") 그 독자가 모를 용어를 그 독자가 아는 단어로 풀어 쓴다.
- 분량은 요약의 조건이고 정한 분량을 넘기지 않는다. 사용자가 줄 수나 글자 수를 정했으면 그 분량을 따른다. 정한 분량에 내용이 다 들어가지 않으면 덜 중요한 사실부터 제외한다. 남긴 문장의 주어, 목적어, 수치의 조건을 생략해 분량을 맞추지 않는다.
- 어투의 규칙은 [tone.md](tone.md)에 있다. 직접 입력한 어투는 tone.md의 "사용자가 직접 정한 어투"를 따른다.

## 질문

settings-protocol.md의 묻는 순서 3에서 Claude Code는 빈 값마다 아래 질문을 만든다. 선택지에 없는 값은 도구가 제공하는 기타 입력란으로 받는다.

| 값 | header | 질문 | 선택지(이름: 설명) |
|---|---|---|---|
| 분량 | 분량 | 요약 분량은 어느 정도로 할까요? | 한 문단(기본값): 3~5문장, 150~300자로 씁니다 / 한 줄: 한두 문장으로 씁니다 / 자세히: 자료의 큰 부분마다 한 문단이나 한 항목으로, 1,000자 안팎으로 씁니다 |
| 어투 | 어투 | 어떤 어투로 쓸까요? | Default 합니다체(기본값) / Casual 해요체 / Plain 해라체: 문장을 "~다"로 끝냅니다 |

Codex에서는 같은 질문과 선택지를 대화에 적어 묻고 답을 기다린다.

## 정한 값을 사용하는 위치

- 정한 독자, 분량, 어투는 fact sheet 맨 위의 "독자", "분량", "어투" 줄에 적는다(drafting.md).
- 5단계 subagent에는 정한 독자를 prompt로 전달한다(validation.md).
- 어투가 Default가 아니면 6단계를 수행한다.
- 설정값과 값마다 출처(요청, 사용자 선택, 기본값)는 7단계 보고에 적는다.
