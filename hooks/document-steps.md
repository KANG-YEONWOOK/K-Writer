# 문서 작성 순서

이 순서는 K-Writer 스킬을 실행하지 않고 한국어 문서를 파일로 쓸 때 따른다. README, 안내서, 보고서처럼 헤딩이 둘 이상이거나 본문이 다섯 문단 이상인 문서가 대상이다. 문서에 쓸 내용은 설계 문서에 먼저 정하고, 정한 문장을 하나씩 쓴 뒤 검사 명령으로 글 전체를 한 번 확인한다. 아래 명령에서 macOS와 Linux는 `python3`, Windows는 `python`을 실행한다.

## 1. 작업 폴더와 사실 확인

- 설계 문서와 검사 스크립트의 작업 파일을 저장할 작업 폴더를 하나 정한다. 세션에 임시 작업 폴더가 정해져 있으면 그 폴더를 사용한다. 정해진 폴더가 없으면 문서와 같은 폴더를 사용하고 아래 검사 명령에서 `--work`를 생략한다.
- 문서에 쓸 값, 이름, 명령, 순서는 코드, 자료, 실행 결과에서 확인한다. 확인한 곳은 설계 문서의 근거에 적는다.

## 2. 설계

- 설계 문서를 `<작업 폴더>/<이름>.plan.md`에 아래 "설계 문서 형식"으로 쓴다. `<이름>`은 문서 파일 이름에서 `.md`를 제외한 부분이다. 문서가 `README.md`면 설계 문서는 `README.plan.md`다.
- 핵심 주제, 단위마다 전할 내용과 전개, 문장마다 전할 내용을 차례로 적는다. 헤딩이 있는 문서는 섹션 하나가 단위 하나이고, 섹션 안의 문단마다 그 문단이 전할 내용을 적는다.
- 계획 문장은 주어, 목적어, 값, 조건, 서술어를 갖춘 문장으로 적는다. 근거에는 fact sheet 항목 대신 그 사실을 확인한 곳을 적는다. 예: "(sync.py의 사용법 주석)", "(회의록 3번 항목)".
- 핵심 주제를 설명하지 않는 사실은 단위로 정하지 않고 "제외한 사실"에 이유와 함께 적는다. 독자가 따라 하는 데 필요한 값과 순서, 결론이 성립하는 조건은 제외하지 않는다.
- 설계 검사 명령을 실행하고 출력된 항목을 읽어 설계 문서를 수정한다.

```
python3 "<K-Writer 경로>/skills/write/scripts/plan_ko.py" check "<작업 폴더>/<이름>.plan.md"
```

## 3. 문장 쓰기와 단위 점검

- 설계 문서의 문장을 순서대로 하나씩 문서의 문장으로 쓴다. 문장을 쓴 직후에 그 문장의 표현을 확인한다. 단위의 문장을 모두 쓰면 그 단위를 한 번 읽어 문장의 연결과 전개 순서, 용어와 수치의 일치를 확인한다.
- 쓰는 동안 문장을 추가하거나 제외하거나 순서를 바꿔야 하면 설계 문서를 먼저 수정한다.
- 문장 규칙이 더 필요하면 아래 명령으로 문장 규칙 문서의 섹션을 읽는다. 섹션 이름은 "문장을 이어 쓰기", "처음 나오는 용어와 중심 대상 설명", "주어, 목적어, 부사와 맞는 서술어", "제목과 헤딩"이다.

```
python3 "<K-Writer 경로>/skills/write/scripts/section.py" style-guide.md "문장을 이어 쓰기"
```

## 4. 글 전체 검사

- 문서를 다 쓰면 검사 명령을 한 번 실행한다. `--work`를 붙이면 검사 스크립트가 작업 파일을 작업 폴더에 저장하고 같은 폴더의 설계 문서와 글을 대조한다.

```
python3 "<K-Writer 경로>/skills/write/scripts/check_ko.py" "<문서 파일>" --tone auto --work "<작업 폴더>"
```

- 출력의 "반드시 수정할 항목"은 수정한다. 점검 후보와 "설계 대조"는 출력된 문장을 읽고 해당하는 문장만 수정한다. 수정 방법은 출력의 "수정 방향"을 따른다.
- 수정한 뒤 같은 명령을 다시 실행하면 수정한 문장과 그 앞뒤 세 문장씩만 검사한다. 이미 확인한 문장은 다시 읽지 않는다.
- Python을 실행할 수 없으면 기본 글쓰기 방식의 "점검하기"대로 직접 점검하고, 검사 스크립트를 실행하지 못했다고 사용자에게 알린다.

## 5. 정리와 보고

- 설계 문서(`<이름>.plan.md`)와 검사 스크립트가 저장한 `<이름>.checked.md`를 삭제한다.
- 사용자에게 문서의 경로와 검사 판정을 알린다. 코드나 자료에서 확인하지 못해 쓰지 않은 내용이 있으면 함께 알린다.
