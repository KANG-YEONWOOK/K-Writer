## 헬피: 24시간 응대하는 AI 고객 지원 챗봇
### 반복 문의는 챗봇이 해결하고, 상담사는 어려운 문의에 집중합니다
- 전체 문의의 68%를 상담사 없이 자동 해결
- 평균 첫 응답 시간 5초
- 계약 후 2주 만에 운영 시작

## 문의는 늘어나는데 상담 인력은 그대로입니다
### 고객 지원팀이 매일 겪는 세 가지 문제
- 반복 문의: 전체 문의의 70%가 배송 조회, 환불 절차, 비밀번호 재설정 같은 같은 질문
- 응답 지연: 야간과 주말에 들어온 문의는 평균 9시간 뒤에 첫 답변
- 인력 확충의 한계: 상담사 1명을 채용해 현장에 투입하기까지 평균 6주 소요

## 헬피는 귀사의 자료를 학습해 고객 질문에 바로 답합니다
### 도움말, 정책 문서, 과거 상담 내역에 근거한 답변
- 학습 자료: 도움말 센터, 약관·정책 문서, 과거 상담 내역, 상품 정보
- 답변 방식: 질문의 의도를 파악하고 근거 문서에서 찾은 내용으로 응답
- 처리 범위: 주문 조회, 환불 접수, 예약 변경처럼 시스템 처리가 필요한 업무까지 수행
- 답할 수 없는 문의: 대화 내용을 요약해 상담사에게 전달

## 상담 현장에 필요한 기능을 모두 갖췄습니다
### 핵심 기능 네 가지
- 자동 답변: 자연어 질문을 이해하고 한국어·영어·일본어·중국어로 응답
- 업무 처리: 주문 조회, 환불 접수, 예약 변경을 대화 안에서 완료
- 상담사 연결: 불만이 감지되거나 고객이 요청하면 대화 요약과 함께 즉시 전환
- 분석 대시보드: 문의 유형, 해결률, 미해결 질문을 한 화면에서 확인

## 지금 쓰는 채널과 시스템에 그대로 연결됩니다
### 연동 범위와 보안
- 채널: 웹사이트 채팅, 모바일 앱, 카카오톡 채널, 이메일
- 시스템: 주문·회원 DB, CRM, 기존 상담 솔루션과 API로 연동
- 개인정보 보호: 개인정보 자동 마스킹, 전송·저장 데이터 암호화
- 데이터 관리: 고객 데이터는 AI 모델 학습에 쓰지 않으며, 접근 권한과 대화 이력을 감사 로그로 기록

## 도입 3개월이면 효과가 수치로 확인됩니다
### 도입 고객사 120곳 평균 (도입 전 → 도입 3개월 후)
- 자동 해결률: 0% → 68%
- 평균 첫 응답 시간: 3시간 20분 → 5초
- 문의 1건당 처리 비용: 4,200원 → 2,600원 (38% 절감)
- 고객 만족도: 3.9점 → 4.5점 (5점 만점)

## 패션몰 A사는 세일 기간 대기 시간을 27분에서 2분으로 줄였습니다
### 월 문의 3만 건, 상담사 12명 규모의 도입 사례
- 도입 전: 세일 기간마다 문의가 3배로 늘어 평균 대기 시간 27분
- 도입 후: 월 문의 3만 건 중 2만 1천 건(70%)을 헬피가 자동 해결
- 대기 시간: 세일 기간에도 평균 2분 유지
- 인력 운영: 분기마다 6명씩 뽑던 임시 상담 인력을 0명으로 축소

## 계약부터 운영 시작까지 2주면 충분합니다
### 전담 매니저가 함께하는 4단계 도입 절차
1. 1~3일 차: 문의 유형 분석과 자동화 대상 선정
2. 4~7일 차: 도움말·정책 문서 학습, 주문·회원 시스템 연동
3. 8~11일 차: 과거 문의 500건으로 답변 품질 검증 및 보완
4. 12~14일 차: 일부 채널에 먼저 적용한 뒤 전체 채널로 확대
