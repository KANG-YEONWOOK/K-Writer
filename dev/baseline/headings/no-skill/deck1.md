## 임직원 PC의 보안 상태를 매일 자동으로 점검합니다
### 엔드포인트 보안 점검 에이전트 소개
- 설치 한 번으로 OS 설정 120개 항목과 미적용 패치를 매일 점검
- 취약 항목은 사용자 화면에서 바로 조치, 결과는 관리자 콘솔에 자동 집계
- 2주 시범 운영으로 귀사 환경에서 효과 확인 제안

## 분기 1회 수동 점검으로는 PC의 취약 상태를 놓칩니다
### 점검 사이의 공백과 사람 손에 의존하는 방식의 한계
- 점검 주기: 분기 1회 점검 시 설정 변경과 신규 취약점이 최대 90일간 방치
- 점검 인력: PC 3,000대 기준 체크리스트 배포·취합·검증에 담당자 2명이 3주 소요
- 결과 신뢰도: 사용자 자가 응답과 실제 설정의 불일치율 27%
- 사후 조치: 취약 항목 통보 후 30일 내 조치 완료율 58%

## 에이전트가 점검부터 조치 확인까지 자동으로 처리합니다
### 설치, 점검, 보고, 조치의 4단계 흐름
- 1단계 설치: 배포 도구나 설치 파일로 전사 PC에 에이전트 일괄 설치
- 2단계 점검: 정해진 일정에 OS 설정과 설치 소프트웨어의 취약점 검사
- 3단계 보고: 결과를 관리 서버로 전송하고 콘솔에서 전사 현황 집계
- 4단계 조치: 취약 항목을 사용자에게 안내하고 조치 여부 재점검

## OS 설정 120개 항목과 미적용 패치를 한 번에 검사합니다
### 점검 범위: 설정, 취약점, 보안 소프트웨어
- 계정·인증: 암호 길이와 변경 주기, 화면 잠금 대기 시간, 불필요한 관리자 계정
- 시스템 설정: 방화벽, 디스크 암호화, 공유 폴더, 원격 접속, 자동 업데이트
- 취약점: OS와 주요 소프트웨어의 미적용 보안 패치, 지원 종료 버전
- 보안 소프트웨어: 백신 설치 여부, 실시간 감시 상태, 엔진 최신 여부
- 맞춤 항목: 귀사 보안 정책에 맞춘 점검 항목 추가와 기준값 변경

## 업무에 지장을 주지 않도록 가볍게 동작합니다
### 시스템 구성과 PC 부하
- 구성: PC의 에이전트, 결과를 모으는 관리 서버, 관리자용 웹 콘솔
- 부하: 점검 중 CPU 평균 3% 이하, 메모리 80MB 이하, 전체 점검 2분 이내
- 통신: 에이전트와 서버 간 전 구간 암호화, 사내망 전용 구성 지원
- 수집 범위: 설정값과 소프트웨어 목록만 수집, 개인 파일·화면·입력 내용 미수집
- 지원 환경: Windows 10/11, macOS 13 이상

## 전사 PC의 보안 수준을 한 화면에서 확인합니다
### 관리자 콘솔의 대시보드와 보고서
- 보안 점수: PC별·부서별 100점 만점 점수와 기간별 추이
- 취약 현황: 항목별 취약 PC 수, 미조치 기간, 담당 부서
- 정책 관리: 부서·직군별 점검 항목과 주기 설정, 예외 PC 지정
- 보고서: 월간 점검 결과를 PDF와 엑셀로 자동 생성

## 취약 항목은 사용자가 직접, 대부분 클릭 한 번으로 조치합니다
### 자가 조치 안내와 미조치 PC 관리
- 조치 안내: 취약 항목과 해결 방법을 사용자 PC 화면에 알림으로 표시
- 자동 조치: 화면 잠금, 방화벽 등 설정 항목의 85%를 버튼 한 번으로 수정
- 재점검: 조치 직후 해당 항목을 다시 검사해 결과를 즉시 반영
- 미조치 관리: 기한 초과 시 사용자와 부서장에게 단계별 알림, 네트워크 접근 제어(NAC) 연동

## 인증 심사와 내부 감사에 필요한 증적을 자동으로 남깁니다
### 규제·인증 기준 대응
- 기준 매핑: ISMS-P, ISO 27001의 단말 보안 요구 사항과 점검 항목 연결
- 증적 보관: PC별 점검 이력과 조치 기록을 3년간 보관
- 감사 보고서: 기준별 충족 현황 보고서를 요청 시점에 즉시 출력
- 변경 추적: 정책 변경과 예외 승인 내역을 관리자 계정별로 기록
