## 요약

3분기(7월 1일~9월 30일)에는 장애가 7건 발생해 2분기 11건보다 4건 줄었고, 가용성은 99.96%로 목표 99.95%를 달성했습니다. 평균 복구 시간(MTTR)도 34분에서 22분으로 줄었습니다. 다만 8월에 SEV1 장애가 1건 발생했고, p99 응답 시간은 780ms로 목표 750ms에 미치지 못했습니다. 4분기에는 배포 안정성 강화와 연말 피크 대비 용량 확보에 집중합니다.

## 장애 현황

### 전체 현황

장애 건수, 탐지 시간, 복구 시간이 모두 2분기보다 개선됐습니다. 등급은 핵심 기능 전면 중단을 SEV1, 핵심 기능 일부 저하를 SEV2, 부가 기능 영향을 SEV3로 분류합니다.

| 구분 | 2분기 | 3분기 | 증감 |
| --- | --- | --- | --- |
| 전체 장애 건수 | 11건 | 7건 | −4건 |
| SEV1 | 2건 | 1건 | −1건 |
| SEV2 | 3건 | 2건 | −1건 |
| SEV3 | 6건 | 4건 | −2건 |
| 평균 탐지 시간(MTTD) | 9분 | 4분 | −5분 |
| 평균 복구 시간(MTTR) | 34분 | 22분 | −12분 |
| 총 장애 영향 시간 | 374분 | 154분 | −220분 |

### 주요 장애 내역

SEV1과 SEV2 장애는 아래 3건입니다.

| 발생일 | 등급 | 내용 | 원인 | 복구 시간 |
| --- | --- | --- | --- | --- |
| 7월 14일 | SEV2 | 결제 API 응답 지연 | DB 커넥션 풀 고갈 | 23분 |
| 8월 21일 | SEV1 | 전체 사용자 로그인 불가 | 인증 서비스 배포 시 설정 값 누락 | 41분 |
| 9월 9일 | SEV2 | 푸시 알림 발송 지연 | 메시지 큐 적체 | 35분 |

SEV3 4건은 관리자 화면, 통계 조회 등 부가 기능에 한정됐고, 복구 시간은 각각 9분, 12분, 16분, 18분이었습니다.

### 원인 분석과 조치

배포·변경으로 인한 장애가 3건으로 가장 많았고, 용량 부족이 2건으로 뒤를 이었습니다.

| 원인 유형 | 건수 | 해당 장애 |
| --- | --- | --- |
| 배포·변경 | 3건 | SEV1 1건, SEV3 2건 |
| 용량 부족 | 2건 | SEV2 2건 |
| 외부 의존성 | 1건 | SEV3 1건 |
| 인증서 만료 | 1건 | SEV3 1건 |

- **배포·변경:** 8월 SEV1 장애 이후 인증 서비스에 카나리 배포를 적용했고, 배포 파이프라인에 설정 값 검증 단계를 추가했습니다(9월 완료).
- **용량 부족:** 커넥션 풀 상한을 올리고 큐 적체 알림을 추가했습니다. 이는 임시 조치이며, 자동 확장은 4분기 과제로 넘겼습니다.
- **인증서 만료:** 수동으로 갱신해 복구했습니다. 자동 갱신은 4분기에 적용합니다.

## 성능 지표

### 핵심 지표

6개 지표 중 4개가 목표를 달성했고, p99 응답 시간과 SEV1 장애 건수는 미달했습니다.

| 지표 | 목표 | 2분기 | 3분기 | 달성 여부 |
| --- | --- | --- | --- | --- |
| 가용성(요청 성공률) | 99.95% 이상 | 99.91% | 99.96% | 달성 |
| 5xx 오류율 | 0.05% 이하 | 0.09% | 0.04% | 달성 |
| 응답 시간 p50 | 100ms 이하 | 88ms | 82ms | 달성 |
| 응답 시간 p95 | 350ms 이하 | 385ms | 310ms | 달성 |
| 응답 시간 p99 | 750ms 이하 | 940ms | 780ms | 미달 |
| SEV1 장애 | 0건 | 2건 | 1건 | 미달 |

p99 응답 시간은 2분기보다 160ms 줄었지만 목표에는 30ms 모자랍니다. 지연의 약 60%가 주문 내역 조회, 정산 리포트 등 상위 10개 쿼리에서 발생하고 있어, 이 쿼리들을 4분기에 우선 개선합니다.

트래픽이 13.6% 늘었는데도 응답 시간과 오류율은 모두 개선됐습니다. 배포 횟수는 늘었고, 장애를 일으킨 배포의 비율인 변경 실패율은 6.1%에서 2.4%로 내려갔습니다.

### 주요 과제

1. **배포 안정성 강화:** 카나리 배포 적용 범위를 전체 서비스의 60%에서 100%로 넓히고, 설정 값 자동 검증을 모든 배포 파이프라인에 적용합니다.
2. **연말 피크 대비 용량 확보:** 4분기 피크는 3분기의 약 1.3배인 초당 2,800건으로 예상합니다. DB 커넥션 풀과 메시지 큐에 자동 확장을 적용하고, 예상 피크 기준으로 부하 테스트를 진행합니다.
3. **p99 응답 시간 개선:** 느린 쿼리 상위 10개를 튜닝하고, 조회 빈도가 높은 API에 캐시를 적용합니다.
4. **사전 탐지 확대:** 인증서 자동 갱신을 적용하고, 외부 연동 서비스의 상태 모니터링과 알림을 추가합니다.
