# 두 글 비교 판정 지침

폴더에는 자료(`source.*`)와 같은 자료, 같은 요청으로 쓴 한국어 글 두 편(`A.md`, `B.md`)이 있다. 요청과 독자는 `request.md`에 있다. 두 글을 그 독자의 입장에서 읽고 아래 항목을 판정해 JSON 하나로 답한다. 어느 글이 어떤 방법으로 작성됐는지는 알려 주지 않으며 추측하지 않는다. 글의 길이나 형식(표, 목록) 자체로 점수를 주지 않고, 독자가 이 글만 읽고 요청의 목적을 이루는 데 도움이 되는지로 판단한다.

## 읽는 순서

1. `request.md`를 읽고 독자와 목적을 확인한다.
2. `A.md`를 처음부터 끝까지 읽는다. 문단마다 그 문단이 전하는 내용을 한 줄로 정리하고 글의 핵심을 한 문장으로 정리한다. `B.md`도 같은 방법으로 읽는다.
3. `source.*`를 읽는다. 자료가 길면 글이 다루는 부분을 찾아 읽는다.
4. 두 글에서 아래 여섯 가지를 찾아 문장을 인용해 적는다. 없으면 빈 배열로 둔다. 억지로 찾지 않는다.
   - `off_topic`: 글의 핵심과 요청의 목적에 관계없는 문단이나 문장. 삭제해도 독자가 잃는 것이 없는 내용이다.
   - `skipped`: 독자가 이유, 과정, 조건, 값을 스스로 채워야 하는 곳. 자료에 그 내용이 있는데 글이 줄이거나 빼서 결과만 말한 경우만 적는다. 자료에도 없는 내용은 적지 않는다.
   - `missing`: 자료에 있고 독자가 목적을 이루는 데 필요한데 글에 없는 사실.
   - `unlinked`: 앞 문장과 어떻게 이어지는지 알 수 없는 문장, 문단의 내용과 맞지 않는 문장.
   - `compressed`: 조사 없이 명사를 이어 붙인 구, 설명 없이 사용한 용어, 기호나 약어로 줄여 쓴 표현.
   - `wrong`: 자료와 다른 사실, 자료에 없는 사실.
   - `awkward`: 한국어로 어색한 표현(직역, 주어와 어울리지 않는 서술어, 사람이 그 의미로 사용하지 않는 단어).
5. 항목마다 어느 글이 나은지 판정한다. 차이가 없으면 `tie`다.

## 출력 형식

```json
{
 "A": {"main_point": "글의 핵심 한 문장", "off_topic": ["문장"], "skipped": ["문장: 빠진 내용"], "missing": ["빠진 사실"], "unlinked": ["문장"], "compressed": ["표현"], "wrong": ["문장: 자료의 내용"], "awkward": ["표현"]},
 "B": {"main_point": "...", "off_topic": [], "skipped": [], "missing": [], "unlinked": [], "compressed": [], "wrong": [], "awkward": []},
 "verdict": {
  "topic": {"better": "A|B|tie", "reason": "한 문장"},
  "sufficiency": {"better": "A|B|tie", "reason": "한 문장"},
  "flow": {"better": "A|B|tie", "reason": "한 문장"},
  "facts": {"better": "A|B|tie", "reason": "한 문장"},
  "korean": {"better": "A|B|tie", "reason": "한 문장"},
  "overall": {"better": "A|B|tie", "reason": "한 문장"}
 }
}
```

- `topic`: 글이 핵심에서 벗어나지 않는가(`off_topic`).
- `sufficiency`: 독자에게 필요한 이유, 과정, 값이 줄지 않고 다 있는가(`skipped`, `missing`, `compressed`).
- `flow`: 내용의 순서와 문장의 연결이 자연스러워 한 번 읽고 이해되는가(`unlinked`).
- `facts`: 자료와 같은가(`wrong`).
- `korean`: 한국어로 자연스러운가(`awkward`).
- `overall`: 그 독자가 요청의 목적을 이루는 데 어느 글이 나은가.
