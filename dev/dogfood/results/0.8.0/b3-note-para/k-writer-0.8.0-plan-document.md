# API 처리율 제한을 토큰 버킷으로 바꾼 엔지니어링 노트 요약

공개 API의 처리율 제한을 고정 윈도우에서 클라이언트별 토큰 버킷으로 바꾸자 배포 2주 뒤 같은 트래픽 수준에서 게이트웨이의 p99 지연이 1,850ms에서 420ms로 줄었습니다. 고정 윈도우에서는 60초 구간이 시작될 때마다 제한에 걸렸던 클라이언트들이 동시에 재시도해 요청이 몰렸습니다. 토큰 버킷은 토큰을 최대 100개 담고 초당 10개씩 채워 기존과 같은 분당 600건 한도를 유지합니다. 배포 2주 뒤 1초 동안의 최대 요청 수는 4,800건에서 1,400건으로 줄었습니다. 다만 배포 직후처럼 서로 다른 클라이언트 여러 개가 같은 순간에 요청을 시작하면 짧은 몰림이 여전히 생기고 활성 클라이언트가 50,000개를 넘는 환경에서는 테스트하지 않았습니다.
