# 쿠버네티스 운영 기초를 공부하는 스터디 3기 모집

스터디 3기에 참가하려면 11월 20일(금)까지 사내 게시판의 "스터디 3기 신청" 글에 이름과 소속 팀을 댓글로 남겨 주세요. 스터디 3기는 플랫폼팀이 운영하는 사내 스터디이고 쿠버네티스(K8s, 애플리케이션의 배포와 관리를 자동화하는 오픈소스 플랫폼)의 운영 기초를 공부해요. 교재로는 사내 위키의 "K8s 온보딩" 문서를 사용해요.

신청 대상은 입사 1년 미만 개발자가 우선이고 그 밖의 직원도 신청할 수 있어요. 정원은 6명이며 신청자가 6명을 넘으면 신청한 순서대로 받아요. 정원에 들지 못한 신청자는 다음 기수에 우선 배정돼요.

스터디 3기는 12월 1일(화)에 시작해 8주 동안 매주 화요일 19:00~20:30에 본사 3층 회의실 B에서 모이고, 모임에는 원격으로 참여할 수 없어요. 모임에 가져올 준비물은 개인 노트북이에요. 실습용 클러스터(쿠버네티스가 애플리케이션을 실행하는 서버 묶음)의 계정은 첫 모임에서 발급해요.

결석이 2회를 넘으면 스터디 3기를 수료할 수 없어요. 수료한 참가자는 교육 시간 12시간을 인정받아요.

스터디 3기에 대해 궁금한 점은 사내 메신저로 이도윤 님에게 문의해 주세요.
