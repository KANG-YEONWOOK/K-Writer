# 설계

- 핵심 주제: 팀장은 PR마다 리뷰어 2명을 자동으로 지정하고 500줄이 넘는 PR을 나눠 올리는 방식을 12월 한 달 동안 결제 서비스 저장소에서 시범 운영하는 안을 11월 25일(수)까지 승인할지 결정하게 된다.
- 전개 순서: 제안과 가장 큰 문제 → 지금 방식과 지연의 원인 → 제안 내용과 확인할 지표 → 위험과 대응 → 필요한 것과 결정 요청

## 단위 1. 제안과 가장 큰 문제
- 형태: 제목과 첫 문단
- 전할 내용: 리뷰어 자동 지정과 500줄이 넘는 PR 분할을 12월 한 달 동안 결제 서비스 저장소에서 시범 운영하자는 제안이고, 3분기에 첫 리뷰가 24시간 넘게 걸린 PR이 32%였다.
- 전개: 제안 → 제안이 필요한 근거 수치

- [제목] 리뷰어 자동 지정과 큰 PR 분할의 시범 운영 제안
1. [제안] PR마다 리뷰어 2명을 자동으로 지정하고 500줄이 넘는 PR은 나눠 올리는 방식을 12월 1일부터 31일까지 한 달 동안 결제 서비스 저장소에서 시범 운영할 것을 제안한다. (사실: 제안 1, 제안 2, 시범 운영 기간, 시범 운영 범위)
2. [근거] 3분기에 올라온 PR 412건 중 131건(32%)은 첫 리뷰를 받기까지 24시간 넘게 걸렸고, 18건은 리뷰를 받지 않고 머지됐다. (사실: 3분기 PR 수, 첫 리뷰까지 24시간 넘은 PR, 리뷰 없이 머지된 PR)

## 단위 2. 지금 방식과 리뷰 지연의 원인
- 형태: 문단
- 전할 내용: 지금은 리뷰어를 지정하지 않아 팀원들이 리뷰를 서로 미루고, 특히 500줄 이상인 큰 PR의 리뷰가 늦어진다.
- 전개: 지금 방식 → 작성자가 판단한 원인 → 원인을 보여 주는 수치

3. [배경] 지금은 PR을 올리면 팀 채널에 링크를 올리고 리뷰어를 지정하지 않은 채 팀원 누구나 리뷰한다. (사실: 현재 리뷰 방식)
4. [원인] 이 방식에서는 누가 리뷰할지 정해져 있지 않아 팀원들이 리뷰를 서로 미루는 것이 리뷰 지연의 원인이라고 판단한다. (사실: 지연 원인)
5. [근거] 변경이 500줄 이상인 큰 PR은 리뷰가 특히 늦어져서, 첫 리뷰까지 24시간 넘게 걸린 PR 131건 중 74건이 큰 PR이었다. (사실: 큰 PR 지연)

## 단위 3. 제안 내용과 확인할 지표
- 형태: 문단
- 전할 내용: 리뷰어 2명은 코드 소유자 파일을 기준으로 주 단위 순번에 따라 지정하고, 시범 운영의 효과는 첫 리뷰까지 걸린 시간의 중앙값과 24시간을 넘긴 PR의 비율로 확인한다.
- 전개: 리뷰어를 지정하는 방법 → 나눌 수 없는 PR의 예외 → 효과를 확인할 지표

6. [방법] 리뷰어 2명은 PR을 올릴 때 코드 소유자 파일을 기준으로 주 단위 순번에 따라 자동으로 지정한다. (사실: 제안 1)
7. [방법] 500줄이 넘는 PR은 올리기 전에 나눠 올리고, 나눌 수 없으면 PR 설명에 나누지 못한 이유를 적는다. (사실: 제안 2)
8. [계획] 시범 운영의 효과는 첫 리뷰까지 걸린 시간의 중앙값(3분기 9.5시간)과 첫 리뷰까지 24시간을 넘긴 PR의 비율(3분기 32%)로 확인할 계획이다. (사실: 지표 1, 지표 2)

## 단위 4. 위험과 대응
- 형태: 문단
- 전할 내용: 리뷰어 순번이 휴가자에게 돌아갈 수 있고, 휴가 캘린더 연동이 아직 없어서 시범 기간에는 리뷰어를 수동으로 바꿔 지정한다.
- 전개: 위험 → 위험을 막는 기능이 아직 없음 → 시범 기간의 대응

9. [위험] 리뷰어 순번이 휴가 중인 팀원에게 돌아갈 수 있는데, 자동 지정을 휴가 캘린더와 연동하는 기능은 아직 없다. (사실: 우려)
10. [대응] 시범 기간에는 순번이 휴가 중인 팀원에게 돌아가면 리뷰어를 수동으로 바꿔 지정한다. (사실: 우려 대응)

## 단위 5. 필요한 것과 결정 요청
- 형태: 문단
- 전할 내용: 시범 운영에는 팀장 승인과 인프라팀에 요청해 하루가 걸리는 저장소 설정 변경 권한이 필요하고, 팀장은 11월 25일(수)까지 결정해야 한다.
- 전개: 필요한 것 → 권한을 받는 데 걸리는 시간 → 결정 요청

11. [조건] 시범 운영을 시작하려면 팀장님의 승인과 저장소 설정 변경 권한이 필요하고, 저장소 설정 변경 권한은 인프라팀에 요청해 받는 데 하루가 걸린다. (사실: 필요한 것 1, 필요한 것 2)
12. [요청] 11월 25일(수)까지 시범 운영의 승인 여부를 결정해 주기를 요청한다. (사실: 결정 기한)

## 제외한 사실
- 첫 리뷰까지 48시간 넘은 PR 47건: 500자 안팎의 분량에서 24시간 넘은 PR 131건(32%)과 리뷰 없이 머지된 PR 18건이 문제를 보여 주고, 47건은 131건에 포함되는 값이라 새 근거를 더하지 않는다.
