# 리뷰어 자동 지정과 큰 PR 분할의 시범 운영 제안

PR마다 리뷰어 2명을 자동으로 지정하고 500줄이 넘는 PR은 나눠 올리는 방식을 12월 1일부터 31일까지 결제 서비스 저장소에서 시범 운영할 것을 제안합니다. 3분기에 올라온 PR 412건 중 131건(32%)은 첫 리뷰까지 24시간 넘게 걸렸고 18건은 리뷰 없이 머지됐습니다.

지금은 PR을 올리면 팀 채널에 링크를 공유하고 리뷰어를 지정하지 않은 채 팀원 누구나 리뷰합니다. 이 방식에서는 리뷰할 사람이 정해져 있지 않아 팀원들이 리뷰를 서로 미루는 것이 첫 리뷰가 늦어지는 원인이라고 판단합니다. 리뷰는 변경이 500줄 이상인 큰 PR에서 특히 늦어졌고 첫 리뷰까지 24시간 넘게 걸린 PR 131건 중 74건이 큰 PR이었습니다.

제안한 방식에서는 PR을 올릴 때 코드 소유자 파일을 기준으로 주 단위 순번에 따라 리뷰어 2명을 자동으로 지정합니다. 변경이 500줄을 넘으면 PR을 올리기 전에 나누고, 나눌 수 없으면 PR 설명에 나누지 못한 이유를 적습니다. 시범 운영의 효과는 첫 리뷰까지 걸린 시간의 중앙값(3분기 9.5시간)과 24시간을 넘긴 PR의 비율(3분기 32%)로 확인할 계획입니다.

자동 지정은 아직 휴가 캘린더와 연동되지 않아서 리뷰어 순번이 휴가 중인 팀원에게 돌아갈 수 있습니다. 그래서 시범 기간에는 휴가 중인 팀원이 리뷰어로 지정되면 리뷰어를 수동으로 바꿉니다.

시범 운영을 시작하려면 팀장님의 승인과 저장소 설정을 변경할 권한이 필요합니다. 이 권한은 인프라팀에 요청해 받는 데 하루가 걸립니다. 11월 25일(수)까지 승인 여부를 결정해 주세요.
