# 리뷰어를 자동으로 지정하는 코드 리뷰 방식의 시범 운영 제안

12월 1일부터 31일까지 결제 서비스 저장소에서 PR 리뷰어를 자동으로 지정하고 변경이 500줄을 넘는 PR은 나눠 올리는 방식을 시범 운영할 것을 제안합니다. 3분기 PR 412건 중 131건(32%)은 첫 리뷰를 받기까지 24시간 넘게 걸렸습니다.

지금은 PR을 올리면 팀 채널에 링크를 공유하고 리뷰어를 지정하지 않습니다. 3분기에 첫 리뷰까지 48시간 넘게 걸린 PR은 47건이었고 리뷰 없이 머지된 PR도 18건이었습니다. 리뷰가 늦어지는 원인은 누가 리뷰할지 정해져 있지 않아 팀원들이 리뷰를 서로 미루는 것이라고 추정합니다.

시범 운영에서는 PR을 올리면 경로별 담당자를 적은 코드 소유자 파일과 주 단위 순번을 기준으로 리뷰어 2명을 자동으로 지정합니다. 변경이 500줄 이상인 PR은 리뷰가 특히 늦어져 첫 리뷰까지 24시간 넘게 걸린 PR 131건 중 74건을 차지했습니다. 그래서 변경이 500줄을 넘는 PR은 올리기 전에 나누고 나눌 수 없으면 PR 설명에 이유를 적도록 합니다.

시범 운영의 효과는 첫 리뷰까지 걸린 시간의 중앙값과 첫 리뷰까지 24시간을 넘긴 PR의 비율로 확인합니다. 3분기 값은 각각 9.5시간과 32%입니다.

주 단위 순번은 아직 휴가 캘린더와 연동되지 않아 휴가 중인 팀원이 리뷰어로 지정될 수 있습니다. 시범 기간에는 그런 경우 다른 리뷰어를 수동으로 지정합니다.

시범 운영을 시작하려면 팀장님의 승인과 저장소 설정을 변경할 권한이 필요합니다. 이 권한은 인프라팀에 요청하며 받는 데 하루가 걸립니다. 11월 25일(수)까지 승인 여부를 결정해 주세요.
