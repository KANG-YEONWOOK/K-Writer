# 코드 리뷰 방식 변경 제안

## 제안 요약
### 리뷰어 2명 자동 지정과 변경 500줄 넘는 PR 나눠 올리기

- 3분기 PR의 32%가 첫 리뷰까지 24시간 넘게 걸림
- 12월 1일~31일 결제 서비스 저장소에서 시범 운영
- 11월 25일(수)까지 결정 필요

## 리뷰어를 지정하지 않는 지금의 리뷰 방식
### 3분기 PR 412건 중 첫 리뷰까지 24시간 넘게 걸린 PR 131건(32%)

- PR 링크를 팀 채널에 올리고 팀원 누구나 리뷰
- 첫 리뷰까지 48시간 넘게 걸린 PR 47건
- 리뷰 없이 머지된 PR 18건

## 리뷰 지연의 추정 원인
### 리뷰어 미지정과 변경 500줄 이상의 큰 PR

- 누가 리뷰할지 정해져 있지 않아 리뷰를 서로 미룸
- 변경 500줄 이상인 큰 PR의 리뷰가 특히 늦어짐
- 첫 리뷰까지 24시간 넘게 걸린 PR 131건 중 변경 500줄 이상인 PR 74건

## 리뷰어 자동 지정과 큰 PR 나눠 올리기
### 리뷰어를 정하는 기준과 PR을 나누지 못할 때의 예외

- PR을 올리면 리뷰어 2명 자동 지정
- 리뷰어는 코드 소유자 파일(파일 경로마다 담당자를 적어 둔 파일)을 기준으로 주 단위 순번에 따라 지정
- 변경 500줄을 넘는 PR은 올리기 전에 여러 PR로 나누기
- 나누지 못하면 PR 설명에 나누지 못한 이유 작성

## 시범 운영 계획
### 결제 서비스 저장소에서 12월 1일~31일 운영

- 지표 1: 첫 리뷰까지 걸린 시간의 중앙값, 3분기 값 9.5시간
- 지표 2: 첫 리뷰까지 24시간 넘게 걸린 PR 비율, 3분기 값 32%
- 휴가자 문제: 주 단위 순번에 따라 휴가 중인 팀원이 리뷰어로 지정될 수 있음
- 시범 기간 대응: 자동 지정이 아직 휴가 캘린더와 연동되지 않아 리뷰어를 수동으로 바꿔 지정

## 시범 운영 승인 요청

- 필요한 권한: 저장소 설정 변경 권한
- 권한 요청: 인프라팀에 요청하며 받기까지 하루 걸림
