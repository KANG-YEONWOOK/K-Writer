# PEP 659 Specializing Adaptive Interpreter 요약

PEP 659는 CPython 인터프리터가 실행 중 만난 타입과 값에 맞춰 바이트코드를 명령어 단위로 특수화하고 특수화가 맞지 않으면 적은 비용으로 빠르게 되돌리는 방식을 제안합니다. 특수화할 명령어는 먼저 적응형 명령어로 교체되고 충분히 실행되면 특수화 명령어로 바뀝니다. 특수화 명령어는 입력이 예상과 같으면 카운터를 늘리고 다르면 줄이며 카운터가 최솟값에 이르면 적응형 명령어로 되돌아갑니다. PEP는 실험을 근거로 속도가 최대 50% 빨라질 것으로 추정하지만 이 수치는 벤치마크와 아직 하지 않은 작업에 따라 크게 달라진다고 밝힙니다. PEP 659를 적용한 3.11은 많은 함수가 거의 실행되지 않는 대부분의 애플리케이션에서 3.10보다 메모리를 조금 더 사용합니다.

자료: PEP 659 "Specializing Adaptive Interpreter", Mark Shannon, 2021, pep-0659.rst
