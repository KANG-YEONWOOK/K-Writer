# PEP 659 특수화 적응형 인터프리터 요약

PEP 659는 CPython 인터프리터가 실행 중에 만난 타입과 값에 맞춰 바이트코드 명령 하나 단위로 특수화하고 타입과 값이 달라지면 특수화를 적은 비용으로 되돌리게 하자고 제안합니다. 특수화한 명령은 입력이 예상과 다를 때마다 자신의 카운터를 줄이고 카운터가 최솟값에 이르면 특수화하지 않은 명령으로 되돌아가 주기적으로 다시 특수화를 시도합니다. 저자는 이 특수화로 CPython이 특수화하지 않을 때보다 10~60% 빨라진다고 추정합니다. 이 제안을 적용해도 Python 언어, 라이브러리, API는 바뀌지 않습니다. 다만 대부분의 애플리케이션에서는 함수 상당수가 비교적 적게 실행되어 이 제안을 적용한 3.11이 3.10보다 메모리를 조금 더 사용합니다.

자료: PEP 659 "Specializing Adaptive Interpreter", Mark Shannon, 2021, pep-0659.rst
