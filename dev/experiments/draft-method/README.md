# 초안 작성 방식 비교: 한국어로 바로 쓰기와 영어로 쓴 뒤 옮기기

2026-11-15에 사용자는 점검에 드는 시간과 토큰을 줄이는 방법으로 초안을 영어로 먼저 쓴 뒤 문단과 문장이 전하려는 내용을 고려하면서 한국어로 옮기는 방식을 제안했다. 이 폴더는 그 방식과 지금의 방식(개요에 문단마다 전할 내용을 적고 한국어로 바로 쓰기)을 같은 자료로 비교한 기록이다. 결과가 같은 수준이고 영어로 먼저 쓰는 쪽이 토큰과 시간을 더 사용해서 K-Writer 0.6.0은 한국어로 바로 쓰는 방식을 유지했다.

## 방법

- 자료 3건과 요청은 아래 표와 같다. 설정값은 요청에 모두 적어서 스킬이 묻지 않게 했다.
- 방식마다 자료마다 subagent 하나가 0.5.2의 write 문서(drafting.md, fact-sheet.md, genre.md, style-guide.md)를 읽고 1~4단계(자료 읽기, fact sheet, 개요, 합니다체 초안)만 수행했다. 검사 스크립트와 점검 단계는 실행하지 않았다. 두 방식은 4단계만 다르다.
  - 바로 쓰기: drafting.md에 적힌 대로 fact sheet의 "의미" 칸과 개요를 보고 한국어로 쓴다.
  - 영어로 쓴 뒤 옮기기: 개요에 따라 글 전체를 영어로 먼저 쓰고(`*.en.md`), 문단마다 문장이 전하려는 내용을 파악한 뒤 같은 규칙에 맞는 한국어 문장으로 옮긴다.
- 초안 6편은 0.5.2의 lint(`--tone default`, fact sheet 대조, 본문 1,500자 미만이라 짧은 글 기준)로 검사했다.

| 자료 | 언어 | 요청 |
|---|---|---|
| s1: `dev/dogfood/sources/rate-limiter-note.md` | 영어 | 변경에 참여하지 않은 백엔드 개발자에게 설명하는 글, 1,000자 안팎 |
| s2: `evals/word-choice-draft/source.md` | 영어 | 작업에 참여하지 않은 개발자에게 설명하는 글, 1,200자 안팎 |
| s3: `dev/dogfood/sources/proposal-memo.md` | 한국어 | 팀장에게 보내는 제안 글, 500자 안팎 |

## 결과

| 초안 | 본문 글자 수 | lint 판정 | 한국어 점검 후보 | subagent 토큰 | 시간 |
|---|---|---|---|---|---|
| s1 바로 쓰기 | 996 | PASS(Gate 0, FAIL 0, WARN 0) | 1 | 140,000 | 8.5분 |
| s1 영어로 쓴 뒤 옮기기 | 1,019 | PASS(0, 0, 0) | 0 | 152,700 | 10.1분 |
| s2 바로 쓰기 | 984 | PASS(0, 0, 0) | 0 | 172,000 | 13.7분 |
| s2 영어로 쓴 뒤 옮기기 | 1,090 | PASS(0, 0, 0) | 0 | 182,300 | 14.8분 |
| s3 바로 쓰기 | 544 | PASS(0, 0, 0) | 0 | 132,200 | 7.0분 |
| s3 영어로 쓴 뒤 옮기기 | 549 | PASS(0, 0, 0) | 0 | 151,700 | 10.0분 |

- 여섯 초안 모두 lint를 통과했고 Gate, FAIL, WARN이 없었다. lint로는 두 방식의 차이를 찾지 못했다.
- 영어로 쓴 뒤 옮기는 방식은 subagent 토큰을 평균 9.5%(148,100에서 162,200), 시간을 평균 19%(9.7분에서 11.6분) 더 사용했다.
- 읽어서 비교한 차이는 단어 선택에 있었다. s2에서 바로 쓴 초안은 "색인 지연", "재색인"으로 썼고 영어로 쓴 뒤 옮긴 초안은 "인덱스 지연(index lag)", "인덱싱", "재인덱싱"으로 썼다. s1에서 영어로 쓴 뒤 옮긴 초안에는 "토큰 버킷이 도움이 되지 않아서"처럼 영어 문장의 서술어를 따른 표현이 있었고, 바로 쓴 초안은 같은 내용을 "요청이 몰리는 것을 막지 못해서"로 썼다. 문단 구성과 사실은 두 방식이 같았다.

## 한계

- 자료 3건을 방식마다 한 번씩 실행했다. 실행 간 편차는 측정하지 않았다.
- 두 방식 모두 같은 style-guide.md를 읽고 썼다. 문서를 읽지 않고 쓰는 조건은 비교하지 않았다.
- 초안만 비교했고 점검 단계를 거친 최종 글은 비교하지 않았다. 읽어서 비교한 사람은 이 실험을 설계한 agent 하나다.
