# 코드 리뷰 방식 변경 제안

PR을 올리면 리뷰어 2명을 자동으로 지정하고 변경이 500줄을 넘는 PR은 나눠서 올리는 방식을 12월 1일부터 31일까지 결제 서비스 저장소에서 시범 운영할 것을 제안합니다. 3분기에는 PR 412건 중 131건(32%)이 첫 리뷰까지 24시간이 넘게 걸렸고 리뷰 없이 머지된 PR도 18건 있었습니다.

지금 우리 팀은 PR을 올릴 때 리뷰어를 지정하지 않고 팀 채널에 링크를 올리면 아무나 리뷰합니다. 첫 리뷰가 늦어지는 것은 누가 리뷰할지 정해져 있지 않아 서로 미루기 때문이라고 추정합니다. 변경이 500줄 이상인 큰 PR은 리뷰가 특히 늦어져서 24시간이 넘게 걸린 131건 중 74건이 500줄 이상이었습니다.

새 방식에서는 코드 소유자 파일을 기준으로 주 단위 순번에 따라 리뷰어 2명을 지정합니다. 500줄을 넘는 PR을 나눌 수 없을 때는 PR 설명에 이유를 적습니다.

시범 운영 기간에는 첫 리뷰까지 걸린 시간의 중앙값과 24시간이 넘게 걸린 PR의 비율을 확인합니다. 3분기에 이 중앙값은 9.5시간이었습니다.

리뷰어 자동 지정은 아직 휴가 캘린더와 연동되지 않아서 순번이 휴가 중인 사람에게 돌아갈 수 있습니다. 시범 운영 기간에는 이런 경우에 리뷰어를 수동으로 바꿔 지정합니다.

시범 운영에는 팀장님의 승인과 저장소 설정을 변경할 권한이 필요합니다. 이 권한은 인프라팀에 요청해야 하고 받는 데 하루가 걸립니다. 11월 25일(수)까지 승인 여부를 결정해 주세요.
