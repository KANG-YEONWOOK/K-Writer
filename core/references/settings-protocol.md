# 설정 정하기

skill의 settings.md와 함께 읽는 문서다. 인자를 해석한 뒤 요청에 없는 설정값을 사용자에게 물어 정하고, 그다음에 작업을 시작한다. 설정을 정하기 전에는 자료를 읽거나 fact sheet를 만들지 않는다. 사용자는 독자, 어투, 분량 같은 설정값을 먼저 고르고 그다음에 작업하기를 원한다(2026-10-18 사용자 요청). 어떤 값을 묻는지와 값마다의 기본값, 선택지, 질문 문구는 skill의 settings.md가 정한다.

## 묻는 순서

1. 인자와 요청 문장에서 값을 찾는다. 요청에 있는 값은 다시 묻지 않는다.
2. `--defaults`가 있으면 묻지 않고 빈 값을 기본값으로 채운다. 요청에 "기본값으로", "묻지 말고"가 있어도 같다.
3. 빈 값이 있으면 한 번에 묻는다.
   - Claude Code: AskUserQuestion을 한 번 호출한다. 빈 값마다 질문 하나를 만든다. 기본값을 첫 선택지에 두고 이름 끝에 "(기본값)"을 붙인다. "직접 입력"은 도구가 주는 기타 입력란으로 받는다. 질문의 header, 문구, 선택지는 settings.md의 질문 표를 따른다.
   - Codex: 대화에 빈 값마다 선택지와 기본값을 적어 묻고 사용자의 답을 기다린다.
4. 질문할 수 없으면 기본값으로 진행한다. 질문할 수 없는 경우는 다음과 같다.
   - AskUserQuestion이 도구 목록에 없을 때. skill을 subagent 안에서 실행하면 AskUserQuestion을 쓸 수 없다.
   - 호출이 거부되거나 오류를 낼 때. `claude -p`처럼 답할 사람이 없는 실행에서는 호출이 거부된다.
   - 답이 오지 않을 때
   - 실행 방식(대화형인지 아닌지)으로 나누지 않는다. 실행 방식을 알려 주는 문서화된 값이 없다.
5. 정한 값은 settings.md가 정한 곳에 적는다. fact sheet를 쓰는 skill이면 fact sheet 맨 위의 줄이다.
6. 결과 보고에 값마다 출처(요청, 사용자 선택, 기본값)를 적는다. 질문할 수 없어서 기본값을 썼으면 그 이유도 적는다.

## 지킬 것

- 설정은 메인 대화에서 subagent를 띄우기 전에 정한다. subagent는 AskUserQuestion을 쓸 수 없다. 독립 점검 subagent에는 정한 독자를 prompt로 넘긴다.
- 대화형 질문은 사용자가 답할 때까지 기다린다. 자동 실행(dogfood 실행, plugin eval, `codex exec`)에서는 요청에 값을 모두 적거나 `--defaults`를 붙인다.
- 설정을 물은 뒤 같은 값을 다시 묻지 않는다. 작업 중에 새로 정할 것이 생기면 settings.md의 기본값과 style-guide.md, genre.md의 규칙으로 정하고 결과 보고에 적는다.
